Target architecture

Native where it matters. Shared where it is proven.

Client

Expo React Native Product UI, navigation, state, workouts, Trainer, and settings

Apple edge

Swift and SwiftUI Widgets, App Intents, Spotify, advanced haptics, and future HealthKit

Application server

Existing Vercel API Authoritative lifecycle, AI, durable workflows, idempotency, and policy

System of record

Existing Supabase Authentication, Postgres, RLS, storage, programs, history, and media

The app binary is built with Xcode or EAS Build and distributed by Apple. The backend stays on Vercel and Supabase. No Railway migration is required.
